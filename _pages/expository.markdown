# UGA Algebra Qual Solutions
Solutions to some of the past algebra qualifying exams administered at UGA. I worked on these files as I solved the problems, so at times they read more like journal entries than carefully prepared solutions. I hope this is a feature, not a bug. I occasionally reference another document, `graduate_algebra_notes.pdf`. I don't intend to publish it on my website, but if you would like a copy, send me an email.
- [Algebra Fall 2015](/_data/documents/algebra_qual_solutions/algebra_fall_2015.pdf), also see [Non degenerate forms and dual spaces](/_data/documents/algebra_qual_solutions/non_degenerate_forms_and_dual_spaces.pdf) for question 8
